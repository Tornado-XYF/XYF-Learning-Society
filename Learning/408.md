官方解析：
这道题目主要考察Java中数组的基本概念和特性。

A选项正确:在Java中数组确实是一种特殊的对象,它继承自Object类,可以调用对象的方法。

分析错误选项:
B错误:数组不属于原生类(primitive type)。Java中的原生类型包括byte、short、int、long、float、double、boolean和char。数组是引用类型。

C错误:数组的声明和初始化语法有误。正确的语法应该是:
int[] number = {31,23,33,43,35,63}; 或
int number[] = {31,23,33,43,35,63};
题目中的写法int number=[]={31,23,33,43,35,63}在语法上是错误的。

D错误:数组一旦创建,其大小就是固定的,不能动态改变。如果需要改变数组大小,只能创建一个新的数组,然后将原数组的元素复制过去。这是数组的一个重要特性,也是它区别于ArrayList等集合类的地方。

总之,这道题目主要考察了数组的三个关键特性:是对象类型而非原生类型、有特定的声明语法规则、长度固定不可变。
知识点：数组、Java工程师、2017
